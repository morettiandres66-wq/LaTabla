# La Tabla — demo web

Primera versión de una tienda de tablas de quesos gourmet.

Archivos:
- index.html — estructura y contenido.
- styles.css — diseño responsive.
- script.js — carrito y checkout simulado.

Para probarla:
1. Abrí `index.html` en un navegador.
2. Agregá productos al carrito.
3. Modificá cantidades y probá "Continuar con la compra".
4. Las fotografías se cargan desde Unsplash, por lo que se necesita conexión a Internet.

Importante:
- Los precios, textos, nombre de marca y datos comerciales son ficticios para esta primera versión.
- El checkout es una simulación. Para una tienda real se puede conectar Mercado Pago, WhatsApp, email, un backend y/o un sistema de stock.
